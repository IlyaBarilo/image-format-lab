# Сообщения об уязвимостях

Для уязвимостей предусмотрен приватный канал GitHub Private vulnerability reporting.
Обычные вопросы и ошибки, не связанные с безопасностью, относятся к
[обратной связи](README.md#обратная-связь).

Откройте на странице репозитория **Security → Advisories →
Report a vulnerability**. Если вкладка называется **Security and quality**,
пункт **Advisories** находится в ней. Сообщение отправляется автору приватно.
Не публикуйте детали уязвимости в публичных Discussions.

Достаточно описать, что происходит и как это воспроизвести. По возможности
добавьте браузер, устройство и версию приложения, если она отображается.
Для локальной сборки не нужно искать тег или хеш. Не прикладывайте пароли,
токены, личные данные или изображения, которые нельзя передавать.
