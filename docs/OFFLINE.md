# Image Format Lab — один файл без интернета

Сайт проекта: [Image Format Lab на GitHub](https://github.com/IlyaBarilo/image-format-lab).

Скачайте [image-format-lab.html из последнего релиза](https://github.com/IlyaBarilo/image-format-lab/releases/latest/download/image-format-lab.html)
и откройте сохранённый файл в браузере. Интернет нужен для скачивания;
после этого приложение работает без сети.
Файл содержит приложение, Worker, UPNG/pako, gifenc, UTIF/libjpeg-turbo,
HEIC/AVIF-кодеки libheif/libde265/Kvazaar/libaom, libwebp и libjxl вместе
с лицензиями. Соседние файлы, распаковка, сервер и установка не нужны для
запуска приложения. Все встроенные кодеки запускаются автоматически
при открытии HTML без отдельной надписи о запуске. При ошибке
появляются её описание и **Повторить**, чтобы заново запустить неудавшиеся кодеки.
Изображения обрабатываются на устройстве.
Три крупных модуля хранятся в HTML сжатыми; встроенная pako автоматически
распаковывает их один раз при первом запуске. Для последующих операций
используется восстановленный код. Сеть и ручная распаковка не нужны.

- **Добавить** — общий список файлов для сравнения и конвертации.
- **2/4** — варианты сравнения; **100%**, −/+ и вписывание — масштаб.
- **Эксперименты** — готовые сценарии, именованные наборы,
  их импорт/экспорт и CSV/JSON-отчёт сравнения.
- **Анализ** — гистограммы, Waveform, RGB Parade, вектороскоп, профиль линии,
  карты различий и график размера/метрики для текущих вариантов. Доступны общая
  область, наложение пары ячеек и сохранение графиков в PNG или данных в JSON.
- Флажки списка определяют файлы для **Пакетного конвертирования…**.
  В окне доступны размеры, качество, бюджет файла, предпросмотр и выдача ZIP
  либо отдельных файлов. Для бюджета КБ означает 1000 байт; выбирается наибольшее
  подходящее качество из проверенных значений (до 21 пробы).
- **Сохранить настройки** и запуск запоминают параметры пакета. Закрытие окна
  отбрасывает несохранённые изменения. Исходные файлы и очередь не сохраняются.

При перекодировании сохраняется один неподвижный кадр или одна страница.
Анимация и остальные страницы не переносятся; JPEG/BMP24 заменяют прозрачность
заливкой. При перекодировании JPEG можно сохранять GPano; остальные исходные
метаданные не копируются. Скачивание исходного файла сохраняет его байты.

JPEG кодируется встроенным libjpeg-turbo, обычный WebP — средствами браузера. AVIF, HEIC, JPEG XL и
WebP lossless используют встроенные кодеки; TIFF и ICO сохраняются собственным
кодом приложения. Наличие кодеков не гарантирует открытие всех разновидностей
входных файлов. Кнопки **Добавить** и **Образец** находятся вверху колонки файлов.
Перенос изображения на просмотр сразу открывает его; несколько файлов в колонку
дополняют список, а один добавленный файл выбирается автоматически.
Анализ постоянно виден под просмотром. **Свернуть** оставляет заголовок и размеры;
панель можно вытянуть вверх за полоску или заголовок либо свернуть движением вниз до края.
Режим **Видимая часть** обновляет графики при приближении и перемещении изображения.
В наложении гистограммы/профиля первый график — пастельная заливка, второй —
насыщенный контур. При перетаскивании высоты графики обновляются после отпускания.

Предел исходника — 40 мегапикселей, результатов одного ZIP — 256 МиБ.
ZIP содержит успешную часть также при ошибках/отмене. «Повторить ошибки» использует
параметры исходного запуска. «Передано браузеру» не подтверждает запись на диск.
Масштаб 100% соответствует одному CSS-пикселю на пиксель изображения.
PSNR RGB использует белую подложку; Δα показывает среднюю ошибку прозрачности.
Время обработки в отчёте не является изолированным тестом скорости кодировщика.

Кнопка **Лицензии** показывает условия компонентов и предоставляет уведомления
TXT без интернета. Рабочие библиотеки и лицензии находятся внутри HTML;
исходные ZIP gifenc и HEIC/AVIF предоставляются отдельно. Их скачивание по
настроенным ссылкам требует интернета, работа программы — нет. В локальной
сборке без адресов окно сообщает об этом; исходные ZIP находятся в `vendor/`
проекта. Перед сетевой публикацией нужно предоставить их рядом с HTML,
настроить стабильные адреса именно этого выпуска и проверить доступность.
[Порядок подготовки](PUBLISHING.md).
Версии, источники, SHA-256 и тексты лицензий включены в HTML в блок
`embedded-codecs`; в исходниках они также доступны в `vendor/`.
MIT собственного кода, автор и уведомления о составе поставки включены
в `embedded-notices`. У libheif/libde265 сохраняются условия LGPL, у Kvazaar — BSD-3-Clause; соответствующие исходники и
способ замены включены в отдельный исходный комплект. [Инструкция пересборки](../vendor/sources/heic/README.md).
Для JPEG внутри TIFF используется libjpeg-turbo 3.2.0; его условия IJG/BSD и уведомления
тоже встроены. Архив исходников JPEG и сборщик находятся в репозитории:
[инструкция](../vendor/sources/jpeg/README.md). Самостоятельному HTML они для
работы не нужны; эти разрешительные условия не требуют встраивать исходный архив.
Разработчик редактирует `src/` и запускает `npm --prefix scripts run build`; сборщик
`scripts/build.mjs` создаёт готовый HTML в корне проекта. Node.js нужен только
для сборки HTML. Пересборка самих HEIC/JPEG дополнительно требует C/C++-инструментов
из инструкции; обычный запуск HTML не требует установки библиотек.
Исходники и инструкции для AVIF, WebP lossless и JPEG XL находятся в
[vendor/sources/modern/](../vendor/sources/modern/README.md).
Пользователь выбирает свои изображения после открытия приложения.
