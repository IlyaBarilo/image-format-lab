# Справка приложения

Страницы `formats/` и `concepts/` входят в автономный HTML при сборке. Тексты являются самостоятельными пояснениями; ссылки на официальные документы служат для углублённого чтения и не требуются для работы справки без сети.

Используется намеренно ограниченный набор Markdown: заголовок `#`, разделы `## Название {#ascii-id}`, абзацы, списки `- ` и ссылки `[текст](адрес)`. Внутренние ссылки ведут на относительный `.md` с необязательным `#section-id`; внешние — на `https://`. Сборка проверяет адреса и разделы. Каждая страница начинается с раздела `overview`.

Описание стандарта отделяйте от проверенной поддержки конкретного приложения. Не переносите сюда чужие формулировки, таблицы и изображения. Если поддержка меняется, одновременно проверяйте соответствующую статью и контекстную ссылку.
