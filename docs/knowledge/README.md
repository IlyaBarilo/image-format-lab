# Справка приложения

Страницы `formats/`, `concepts/`, `analysis/` и `workflow/` входят в автономный HTML при сборке. Тексты являются самостоятельными пояснениями. Ссылки на стандарты, научные работы, иллюстрированные руководства и отобранные статьи служат для углублённого чтения и не требуются для работы справки без сети.

Используется намеренно ограниченный набор Markdown: заголовок `#`, разделы `## Название {#ascii-id}`, абзацы, списки `- `, ссылки `[текст](адрес)` и отдельные строки `::diagram chroma`, `::diagram histogram-waveform`, `::diagram analysis-area`. Внутренние ссылки ведут на относительный `.md` с необязательным `#section-id`; внешние — на `https://`. Сборка проверяет внутренние адреса, разделы и имена схем. Каждая страница начинается с раздела `overview`.

Описание метода отделяйте от проверенной поддержки конкретного приложения. Указывайте смысл осей, подложки, области анализа, ограничения и конкретное действие пользователя. Не переносите сюда чужие формулировки, таблицы и изображения; три встроенные схемы нарисованы собственным кодом. Ссылки на другие программы обозначайте как примеры внешнего вида, а не описание расчёта Image Format Lab. Если поддержка меняется, одновременно проверяйте соответствующую статью и контекстную ссылку.
