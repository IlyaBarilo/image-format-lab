# Пространственные различия и SSIM

## Коротко {#overview}

Эти режимы сопоставляют результат с исходным изображением. Для попиксельных методов нужны одинаковые размеры: программа не подгоняет изображения и не совмещает их содержимое автоматически. Выбранная область анализа ограничивает расчёт графика, а основные показатели ячейки остаются рассчитанными по полному изображению.

## Различия с исходником {#difference}

Карта показывает местоположение ошибок. Чёрный означает совпадение кодовых значений. Для RGB берётся наибольшая абсолютная разность каналов после выбранной подложки; α сравнивается отдельно без неё. Усиление меняет видимый цвет ошибки, но не измеренное значение. Карта уменьшается максимум до 512 точек по длинной стороне, причём точка удерживает наибольшую ошибку своей группы. Слабая ненулевая ошибка подсвечивается, чтобы не исчезнуть при показе. Это не ΔE и не модель восприятия.

## Границы диапазона {#boundary}

Карта отмечает пиксели с точным кодом 0 или максимальным кодом канала. Голубой указывает 0, оранжевый — максимум, фиолетовый — оба признака. RGB проверяется после подложки, α — по собственному коду. Счётчики считаются до уменьшения карты; в уменьшенной точке признаки могут прийти от разных пикселей. Значение на границе само по себе не доказывает клиппинг, потерю детали или ошибку кодека.

## SSIM {#ssim}

Для каждого пикселя программа оценивает локальное структурное сходство по гауссову окну 11×11, затем усредняет по выбранной области. Используется вычисленный Y′ из нормированных RGB после подложки; отдельная ошибка α не входит. Результат безразмерный: 1 соответствует совпадению по этому методу, но значение не является процентом качества. Реализации SSIM с другим масштабом, граничной обработкой или цветовым методом могут дать иное число. Для оценки характера ошибки сопоставьте SSIM с [PSNR](../concepts/metrics.md#psnr) и картой различий.

## Ограничения сравнения {#limitations}

Известные несовместимые цветовые пространства не смешиваются. Если цветовая метка отсутствует, попиксельные кодовые сравнения не превращаются автоматически в полноценное управление цветом. Сдвиг даже на один пиксель может дать крупную ошибку при визуально похожих изображениях. Карта, SSIM и ΔE00 описывают разные свойства и не заменяют осмотр важных фрагментов.
