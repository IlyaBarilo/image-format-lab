# Разрядность пикселей

## Коротко {#overview}

Разрядность задаёт число уровней одного канала: 8 бит дают 256 целых значений, 16 бит — 65 536. Она отличается от глубины цвета всего пикселя и от качества сжатия. Перезапись 8-битного изображения в 16-битный файл не возвращает отсутствующие исходные уровни.

## В этой программе {#app}

Точные целочисленные 16-битные данные используются там, где это поддерживает путь декодирования и записи, в частности для подходящих PNG16, TIFF16, JPEG XL lossless и JPEG 2000 без потерь без изменения размера. Float16 и float32 — другие представления, их нельзя приравнивать к целым 16 битам. Сведения о точности источника и результата смотрите в паспорте файла и настройках формата.

## Экранный показ {#display}

Разрядность файла, точность расчёта и возможности дисплея — разные вещи. Экранный просмотр может использовать преобразованное SDR-представление, даже если данные анализа или сохраняемый файл содержат больше уровней. Используйте численные показатели для проверки точных значений; 10-битный монитор сам по себе не делает весь тракт приложения 10-битным.
