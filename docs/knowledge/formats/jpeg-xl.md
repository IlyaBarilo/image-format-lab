# JPEG XL

## Коротко {#overview}

JPEG XL поддерживает кодирование с потерями и без потерь. Отдельная возможность формата — восстановление исходных байтов совместимого JPEG из специального JXL-файла; это отличается от сохранения декодированных пикселей без потерь.

## В этой программе {#app}

Режимы «JPEG XL» и «JPEG XL lossless» кодируют изображение для сравнения. В «Экспериментах» есть отдельная операция JPEG → JXL → исходный JPEG с проверкой совпадения байтов. Она не проходит через обычное RGBA-сравнение.

## Настройки {#parameters}

Для кодирования с потерями Q влияет на результат, а «Усилие» — на работу кодировщика. Для lossless доступен выбор 8 или 16 бит/канал; точный 16-битный путь требует исходных данных соответствующей разрядности и исходного размера. См. [разрядность](../concepts/bit-depth.md).
