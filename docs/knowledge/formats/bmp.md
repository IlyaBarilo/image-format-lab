# BMP

## Коротко {#overview}

BMP хранит растровые пиксели в нескольких вариантах разрядности и организации цвета. Файл нередко крупнее сжатых альтернатив, зато устройство простых разновидностей удобно изучать.

## В этой программе {#app}

Единый выбор BMP раскрывает настройки 8-битной палитры, 24-битного RGB и 32-битного RGBA. Для 8-битного режима доступны число цветов и RLE8; для 24-битного прозрачность заливается выбранной подложкой.

## Настройки {#parameters}

RLE8 сжимает повторяющиеся индексы палитры без дополнительного изменения уже выбранных цветов. Ошибка при палитровании и потери прозрачности — отдельные эффекты. См. [прозрачность и подложку](../concepts/alpha.md).
