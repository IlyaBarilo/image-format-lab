# JPEG

## Коротко {#overview}

JPEG обычно выбирают для фотографий и плавных тонов. Обычное кодирование JPEG отбрасывает часть информации: повторное сохранение уже сжатого файла может добавить искажения. Формат не хранит прозрачность.

## В этой программе {#app}

Ячейка сравнения создаёт новый JPEG из декодированных пикселей. Это не побайтовое копирование исходного JPEG. Если исходник прозрачный, выбранная подложка заменяет прозрачность. Режим «GPano в JPEG» переносит только поддерживаемые панорамные данные между JPEG-файлами.

## Настройки {#parameters}

Q управляет кодированием выбранного JPEG, но не равен проценту визуального качества и не сопоставим напрямую с Q другого формата. Переключатель «Прогр.» меняет порядок передачи данных изображения. [Цветность 4:2:0, 4:2:2 и 4:4:4](../concepts/chroma.md) определяет разрешение цветовых компонентов; 4:4:4 не отменяет потери от JPEG-сжатия.
