# GIF

## Коротко {#overview}

GIF хранит цвета через палитру. При переводе полноцветного изображения в ограниченную палитру часть цветов заменяется; само сжатие получившихся индексов не является причиной этой замены. Прозрачность в обычном GIF задаётся индексом палитры, без полупрозрачных уровней.

## В этой программе {#app}

Программа сравнивает и сохраняет статический GIF. «GIF static» и «GIF gifenc» используют разные кодировщики для одного семейства файлов. При открытии многочастного файла для сравнения берётся один кадр.

## Настройки {#parameters}

«Цвета» ограничивает палитру, а Dither распределяет ошибку округления по соседним пикселям. Он может зрительно сгладить градиент, но изменить мелкую фактуру. См. [сжатие и потери](../concepts/compression.md).
