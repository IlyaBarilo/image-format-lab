# ICO

## Коротко {#overview}

Файл ICO может содержать несколько представлений значка разного размера. Поэтому его размер нельзя интерпретировать как размер одного-единственного растра.

## В этой программе {#app}

Сохранение ICO формирует набор из семи размеров из выбранного изображения. Скачанный файл содержит комплект значков, и отдельные размеры могут выглядеть по-разному. При открытии чужого ICO поддержка конкретных внутренних вариантов зависит от декодирования.

## Что проверить {#parameters}

Оценивайте резкие линии и мелкий текст на малых размерах: уменьшение исходника может изменить их даже тогда, когда запись каждого получившегося значка не вносит новых потерь.
