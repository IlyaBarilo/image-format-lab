# Действия по шагам

## Как найти нужную кнопку {#overview}

Найдите название действия или его код поиском слева. В нужном разделе нажмите «Показать в интерфейсе»: справка закроется, нужный элемент будет временно обведён. Escape убирает подсказку. Параметры изображения при этом не меняются. Если нужная кнопка пока недоступна, подсказка объясняет, что сделать сначала.

К адресу открытого HTML можно дописать #help=crop-source, чтобы открыть инструкцию создания исходника. Вместо crop-source подставьте код другой операции из этой страницы. Имя и каталог локального HTML могут различаться, поэтому код можно просто ввести в поиск справки. Адрес открывает только инструкцию; действие выполняете вы.

## Создать исходник из области {#crop-source}

Код: crop-source. Это создание отдельного PNG-фрагмента из исходного изображения. Выбор области для графиков сам по себе не обрезает сохраняемый файл.

- Откройте файл или нажмите стрелку справа от «Образец» и выберите нужный образец. При скрытом списке сначала нажмите «Список» вверху.
- В панели «Анализ» найдите список со значением «Видимая часть» или «Всё изображение» и выберите «Заданная область». Если панель свёрнута, нажмите «Баланс» в её заголовке.
- В открывшемся редакторе выберите «Координаты» → «Пиксели исходника». Введите «Слева, px», «Сверху, px», «Ширина, px», «Высота, px». X направлен вправо, Y вниз; начало в левом верхнем углу исходника.
- Нажмите «Применить область». Редактор закроется, рядом со списком области появится «Создать исходник».
- Нажмите «Создать исходник». Новый PNG добавится в список и откроется для сравнения. Первоначальный файл останется в списке.
- Проверьте размеры нового файла. Для сохранения выберите в одной из ячеек «Исходный файл» и нажмите кнопку скачивания внизу этой ячейки. Для анализа всего нового фрагмента установите «Всё изображение».

Кнопка создания появляется после применения неполной области. Если выделен весь исходник, новый фрагмент не создаётся. Повторный выбор «Заданная область» открывает редактор снова. Подробнее: [область анализа](comparison.md#scope).

## Два или четыре окна {#view-layout}

Код: view-layout. В верхней панели, в группе «Вид», нажмите 2 или 4. Число в левом верхнем углу каждой ячейки обозначает её номер. Выберите формат отдельно в каждой ячейке. Изменение количества окон сохраняет параметры скрытых ячеек, поэтому при возвращении к четырём окнам проверьте их форматы.

«Совмещение» объединяет показ первых двух вариантов; для отдельных ячеек вернитесь к 2 или 4. Если изображения скрыты размером анализа «Максимум», нажмите «Баланс» в заголовке анализа.

## Настроить формат изображения {#format-settings}

Код: format-settings. Над изображением выберите формат из списка рядом с номером ячейки. Его параметры появятся в той же полосе. Настройки действуют только на эту ячейку; пересчёт автоматический.

- JPEG: задайте Q ползунком, «Цветность» 4:2:0, 4:2:2 или 4:4:4 и состояние «Прогр.». Для точного значения Q дайте ползунку фокус и используйте стрелки клавиатуры; число отображается рядом.
- PNG: в поле «Режим» выберите «Полные цвета» или «Палитра». Для полных цветов доступна разрядность; для палитры — число цветов и Dither. «Фильтр» и «Уровень» задают подготовку строк и сжатие PNG. Выбор 16 бит не восстанавливает точность 8-битного исходника.
- BMP: выберите разрядность и доступное сжатие. Для BMP24 используются 24 бита RGB без палитры.
- AVIF: задайте Q и «Скорость». Одинаковое Q у AVIF и JPEG не означает одинакового размера или качества.

Для точных чисел в байтах откройте «Эксперименты» → «Краткая сводка готовых ячеек» → «Скачать краткий CSV» либо «Копировать таблицу». В копии и CSV столбец «Файл, байт» содержит целое число байтов; на экране размер округлён. CSV можно открыть в редакторе таблиц или как текст. [PNG](../formats/png.md#parameters) · [JPEG](../formats/jpeg.md#parameters) · [Метрики](../concepts/metrics.md#overview).

## Выбрать график и область анализа {#graph-settings}

Код: graph-settings. Первый список панели «Анализ» выбирает семейство графика: «Гистограмма», Waveform, Parade и другие. Поле «Модель» гистограммы и Parade выбирает RGB или Y′CbCr. У Waveform в поле «Каналы» доступны Y′, «RGB вместе» и «Y′CbCr вместе». В группе «Вид» выберите «Рядом», «Наложение» или «Разница».

Выберите «Всё изображение», если нужны воспроизводимые графики всего файла. «Видимая часть» зависит от масштаба и перемещения просмотра. «Заданная область» позволяет ввести точные координаты. Подложка анализа задаётся отдельно от фона просмотра. Для графика размера выберите «Размер и метрика», затем «Метрика» → «PSNR RGB».

При смене исходника проверьте область и параметры ячеек. Для сравнения нативных 16-битных данных подходят поддерживаемые точные пути; экранный показ сам по себе не подтверждает разрядность анализа. [Гистограммы](../analysis/histograms.md#overview) · [Пространственные графики](../analysis/spatial.md#overview).

## Задать линию профиля {#analysis-line}

Код: analysis-line. Откройте изображение. В первом списке анализа выберите «Профиль по линии» либо «Профиль ошибки». Появится кнопка «Линия…» (или «Линия ✓», если линия изменена).

Сначала установите область анализа. Нажмите «Линия…» и введите координаты концов A и B в процентах от этой области. Для горизонтальной середины: A · X = 0, A · Y = 50, B · X = 100, B · Y = 50. Нажмите «Применить линию». Кнопка «По центру» также задаёт горизонтальную середину. Линия одна для всех сравниваемых профилей.

При области «Видимая часть» положение линии зависит от просмотра. Для линии по всему файлу сначала выберите «Всё изображение». [Профиль по линии](../analysis/spatial.md#profile).

## Сохранить график PNG {#export-graph}

Код: export-graph. Дождитесь готовности текущих результатов. В панели «Анализ» нажмите PNG. Сохраняется рисунок выбранного анализа с подписями и параметрами. Высота графиков в отчёте не зависит от высоты сжатой панели. Это другая кнопка, чем скачивание изображения внизу каждой ячейки.

Перед сохранением проверьте номера ячеек, их форматы, вид сравнения, область, каналы и подложку. Для следующего рисунка измените нужные параметры и дождитесь пересчёта. JSON рядом сохраняет численные данные анализа; для вставки рисунка в документ нужен PNG.
