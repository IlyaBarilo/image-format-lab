# Пакетное сохранение

## Коротко {#overview}

Отметьте файлы в списке и откройте «Пакетное конвертирование». Пакет имеет собственные параметры, не меняет текущие настройки ячеек сравнения и обрабатывает выбранные файлы последовательно. Результат выдаётся отдельными файлами или одним ZIP. Кодеки уже встроены; сеть для обработки не нужна.

## Настройки и предпросмотр {#settings}

Укажите формат, качество, границы размера, подложку, метаданные и способ выдачи. Маленький исходник не увеличивается из-за верхней границы размеров. Предпросмотр показывает пробный результат и его фактический размер для выбранного файла; сам ничего не скачивает. «Сохранить настройки» и запуск запоминают параметры пакета; закрытие без сохранения отбрасывает черновик. У каждого формата доступен только поддерживаемый набор полей.

## Подбор под размер {#budget}

Для поддерживаемых режимов с потерями можно задать максимум в КБ по 1000 байт и минимальное качество. Верхняя граница — выбранное качество. Программа делает не больше 21 пробы и выбирает самое высокое качество среди проверенных результатов, удовлетворивших фактическому размеру. Это ограниченный поиск, не доказательство оптимума среди всех настроек. Если бюджет недостижим, такой файл не выдаётся.

## Отдельные файлы, ZIP и повтор {#export}

ZIP содержит только успешно обработанные результаты. При отмене или ошибках уже готовая часть может быть доступна как частичный архив. Повтор ошибок использует параметры исходного запуска и не выдаёт успешно обработанные файлы заново. Выдача браузеру не подтверждает, что пользователь сохранил файл на диск. Размер накопленных результатов для одного ZIP ограничен 256 МиБ; при большом наборе выбирайте отдельные файлы.

## Метаданные {#metadata}

Переключатель GPano относится к поддерживаемому пути JPEG. Для остальных форматов не следует ожидать автоматического переноса исходных EXIF, XMP или сведений камеры. Проверяйте фактический результат через [паспорт файла](inspection.md#passport). Перекодирование берёт один неподвижный кадр или страницу; дополнительные кадры и страницы не переходят в результат.
