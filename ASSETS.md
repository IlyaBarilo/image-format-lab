# Image Format Lab — изображения и оформление

Собственные значки, оформление, встроенный образец и синтетические тестовые
изображения распространяются по [MIT проекта](LICENSE).
Автор — [Илья Барило (Ilya Barilo)](https://barilo.ru/).

## Материалы проекта

| Материал | Расположение и назначение |
| --- | --- |
| Значки интерфейса | [src/icons.svg](src/icons.svg), SVG-разметка в [src/index.html](src/index.html) |
| Значок страницы | [src/favicon.svg](src/favicon.svg), встроен в готовый HTML |
| Оформление | [src/styles.css](src/styles.css), светлая и тёмная темы |
| Образец | Создаётся кнопкой **Образец**: геометрия, текст, градиенты и прозрачность |
| Контрольные образцы | Создаются в окне **Эксперименты** из точных пикселей без внешних изображений и шрифтов; файлы в репозитории не хранятся |
| Обложка | [SVG](docs/branding/repository-cover.svg) и [PNG](docs/branding/repository-cover.png) |
| Изображения для тестов | Собственные синтетические файлы в tests/fixtures/ и изображения, создаваемые тестами в памяти |
| ICC-профиль для теста | [tests/fixtures/srgb-test.icc](tests/fixtures/srgb-test.icc): небольшой sRGB-профиль с внутренним уведомлением «No copyright, use freely»; проверяет побайтовое восстановление JPEG с ICC, в готовый HTML не включается |

Обложка — иллюстрация с условными изображениями и графиками. Она не представляет
результаты измерений качества или сжатия. Значки и оформление используют
собственную геометрию; сторонние наборы значков и фотографии не включены.
Шрифты выбираются из установленных на устройстве; файлы шрифтов не поставляются.

Графики анализа строятся программно по пикселям открытого изображения.
Права на исходное изображение при этом сохраняются за его правообладателем.

товарные знаки и изображения, которые пользователь открывает в приложении.

разрешение и сохранить требуемые авторство и уведомления.
